# Third-Party Resources

mcbCode focuses on providing web-based editing and management tools for creating Minecraft: Bedrock Edition content. Detailed information regarding game mechanics, commands, and add-on specifications is maintained by external community and official platforms.

Creators are encouraged to utilize these third-party resources alongside mcbCode to better understand Minecraft Bedrock development.

## Recommended Resources

### wiki.bedrock.dev

[wiki.bedrock.dev](https://wiki.bedrock.dev) is the primary recommended community resource for Minecraft: Bedrock Edition add-on development. It provides comprehensive guides, tutorials, technical documentation, and code examples covering add-ons, scripting, entities, custom blocks, items, manifests, and more. Consult this site when you need to understand how Minecraft's underlying add-on system works.

### Minecraft Wiki

The Minecraft Wiki [minecraft.wiki](https://minecraft.wiki) is an official community-maintained knowledge base. It contains extensive information about vanilla blocks, items, mobs, commands, game mechanics, version history, and general gameplay mechanics. Use this resource when researching core Minecraft gameplay features rather than mcbCode editor functionality.

> **Warning:** The Minecraft Wiki covers both Java Edition and Bedrock Edition. Be aware that Java Edition mechanics, commands, and syntax are often incompatible with Minecraft: Bedrock Edition. Always confirm that you are viewing Bedrock-specific information.

### Microsoft Learn

[Microsoft Learn](https://learn.microsoft.com/en-us/minecraft/creator/) provides the official technical reference documentation published directly by Mojang and Microsoft for Minecraft Bedrock APIs, JSON schemas, and scripting interfaces. Use this site when you require official, authoritative API specifications and syntax references.

## When Should I Use These?

| Task | Recommended Tool / Resource |
| --- | --- |
| Writing, editing, and managing your project files | **mcbCode** |
| Learning add-on structure, entity behaviors, and custom mechanics | **wiki.bedrock.dev** |
| Researching vanilla block properties, redstone rules, and mob behavior | **Minecraft Wiki** |
| Checking official Bedrock Script API syntax and JSON schemas | **Microsoft Learn** |
