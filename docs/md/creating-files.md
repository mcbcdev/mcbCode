# Creating Files

In mcbCode, files store the source code, assets, and configuration data that make up a project. You can create new files directly within the project editor using the File Explorer.

Supported file types depend on the specific project configuration and editor environment.

## Creating a File

Follow these steps to create a new file in your project:

1. Open your project in the mcbCode editor.
2. Locate the **File Explorer** panel.
3. Click the **New File** button or icon in the File Explorer toolbar.
4. Enter the desired file name, including any relevant file extension (e.g., `main.js`, `generateforward.mcfunction`).
5. Press **Enter** or select the confirm action.
6. The new file will immediately appear in the File Explorer list and be ready for editing.

## Notes

* **File Naming:** Choose clear and appropriate file names that match your project's naming conventions.
* **Empty File:** Creating a file generates an empty document; content is not added automatically upon creation.
* **Managing Files:** Files can be renamed or deleted later, provided those actions are supported by your current editor view and permissions.

## Troubleshooting

### File Was Not Created

Ensure that you pressed **Enter** or confirmed the file creation prompt. Check that your network connection is active.

### File With the Same Name Already Exists

mcbCode does not allow duplicate file names within the same directory level. Provide a unique name for the new file.

### Create Option Is Unavailable

If the option to create a file is disabled or missing, you likely do not have edit permissions for the project. Only the project owner or authorized collaborators can add files.
