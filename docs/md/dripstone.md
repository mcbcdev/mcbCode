# dripstoneAI is here! and it's a lot better than i thought.

dripstoneAI is an ai assistant focused on minecraft bedrock edition and addon development. ask it questions, get help understanding bedrock features, troubleshoot errors, or work on a project in mcbcode.

it is designed for bedrock creators at any experience level, from someone making their first behavior pack to someone debugging a larger addon. it keeps bedrock edition at the center of its answers rather than mixing in java edition instructions.

## what dripstoneAI can help with

dripstoneAI can explain, plan, troubleshoot, and help create or update minecraft bedrock addon content, including:

- behavior packs and resource packs
- manifests and json files
- entities, blocks, items, and components
- commands and mcfunctions
- the bedrock scripting api
- animations, sounds, textures, and ui
- addon structure, debugging, and common errors
- brainstorming and improving addon ideas

when an answer depends on a specific bedrock feature or format, dripstoneAI can consult bedrock-focused documentation such as [wiki.bedrock.dev](https://wiki.bedrock.dev/). it can also use relevant files from an mcbcode project to help tailor its answer.

## how to use it

ask in plain language. include what you are trying to make, what is going wrong, and any relevant error message or minecraft version. you do not need to know the exact technical term to get started.

for example:

- “how do i make an item give the player an effect when used?”
- “can you explain what this manifest field does?”
- “my custom entity isn't spawning. can you help me find why?”
- “i want to make a block that slows players down. what should i plan for?”
- “can you review this file and suggest a fix?”

for project-specific help, select or provide access to the relevant mcbcode project in the connected workspace, then describe the task. dripstoneAI can inspect relevant project details and files, search text files, and help make changes through the available mcbcode tools. project access depends on your mcbcode permissions.

## working with mcbcode projects

when connected to mcbcode, dripstoneAI can help inspect project information, find relevant files, read or search text files, and create or update supported project files. the exact actions available depend on the connected tools and your project permissions.

before changing a project, dripstoneAI asks you to approve the proposed edit. you stay in control of project changes, including file or folder operations. after an edit, it summarizes what changed.

## bedrock-first answers

dripstoneAI focuses on minecraft bedrock edition. if a feature or instruction applies only to java edition, it should make that distinction clear instead of presenting it as a bedrock solution. when support depends on a game version, include the version in your question if you know it.

## getting the best results

- describe the goal, not just the file you think needs changing.
- paste the exact error message when something fails.
- mention your minecraft version if compatibility might matter.
- for an existing project, point dripstoneAI to the relevant mcbcode project or file.
- tell it whether you want a quick explanation, a suggested fix, or help changing project files.

## scope

dripstoneAI is a specialized assistant for minecraft bedrock and addon development. answers about unsupported features may include a limitation and a practical bedrock alternative, when one exists. it can make mistakes, so verify critical changes in minecraft and review project edits before using them in a release.
