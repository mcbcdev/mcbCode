# Introduction

Welcome to the mcbCode documentation. mcbCode is an online toolkit for Minecraft Bedrock addon creators.

## What you can do

- Write mcfunction commands with syntax highlighting
- Generate manifest.json files with valid UUIDs
- Edit entity and item JSON
- Write Script API code

## Getting Started

1. Create a free account
2. Open the dashboard
3. Pick an editor workspace
4. Start building
