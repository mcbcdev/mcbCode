# Adding Collaborators to a Project

In mcbCode, collaborators are registered users whom you invite to work on your project. Collaborators can edit the project's code and assets, but they do not become owners of the project.

Use collaborators when you want to work on a single project alongside other mcbCode users.

## Requirements

To add a collaborator, ensure the following conditions are met:

* **Project Ownership:** You must be the owner of the project.
* **Active Account:** The user you want to invite must have an existing mcbCode account.
* **Collaboration Requests Enabled:** The receiving user must have collaboration requests enabled in their account settings.

## Access & Permissions

* **Only the project owner** can add or remove collaborators.
* **Collaborators** have full edit access to the project, but ownership permissions (such as managing collaborators) remain strictly with the owner.

## Adding a Collaborator

To add a collaborator to your project, follow these steps:

1. Open the target project in mcbCode.
2. Select the **Settings** tab.
3. Scroll down to the **Collaborators** section.
4. Search for the user using their exact username.
5. Select the correct user from the autocomplete list.
6. Click **Add**.

## Removing a Collaborator

1. Navigate to the **Settings** tab of your project.
2. Scroll to the **Collaborators** section.
3. Locate the user in the list of current collaborators.
4. Click the **Remove** button next to their name.

## Managing Collaboration Requests

Users have control over who can send them collaboration invitations.

* Users can disable incoming collaboration requests at any time within their account settings. For detailed steps on configuring this preference, see the **Managing Collaboration Requests** documentation page.
* **Impact of Disabling Requests:** Disabling collaboration requests only blocks new incoming invitations.
* **Existing Projects:** Disabling this setting does not affect projects the user is already collaborating on; they can continue editing those projects normally.
* **Project Owners:** Project owners are never affected by this setting for projects they own.

## Troubleshooting

### User Cannot Be Found

* Verify that the username was spelled correctly.
* Ensure the user has an active mcbCode account.

### "Add" Button Fails or Displays an Error

* The user you are trying to add likely has collaboration requests disabled in their account settings. They must enable this option before you can send an invitation.

### Cannot See Options to Add or Remove Collaborators

* Confirm that you are logged into the account that owns the project. Only project owners have permission to manage collaborators.
> **Note:** Additional permission levels, role-based access controls, or transfer of ownership capabilities cannot be confirmed based on current documentation specifications.
