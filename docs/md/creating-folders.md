# Creating Folders

In mcbCode, folders are used to structure and organize your project files. Grouping related files into folders helps maintain a clean project hierarchy, making projects easier to navigate and manage.

## Creating a Folder

Follow these steps to create a new folder in your project:

1. Open your project in the mcbCode editor.
2. Locate the **File Explorer** panel.
3. Click the **New Folder** button or icon in the File Explorer toolbar.
4. Enter the desired folder name.
5. Press **Enter** or select the confirm action.
6. The new folder will immediately appear in the File Explorer hierarchy.

## Notes

* **Structure:** Folders can contain files as well as nested subfolders.
* **Organization:** Organizing projects into folders is recommended for larger projects to keep assets and source files structured.
* **Managing Folders:** Folders can be renamed or deleted later, provided those operations are supported by your current editor view and permissions.

## Troubleshooting

### Folder Was Not Created

Ensure that you pressed **Enter** or confirmed the folder creation prompt. Check that your network connection is active.

### Folder With the Same Name Already Exists

mcbCode does not allow duplicate folder names within the same directory level. Provide a unique name for the new folder.

### Create Option Is Unavailable

If the option to create a folder is disabled or missing, you likely do not have edit permissions for the project. Only the project owner or authorized collaborators can create folders.

> **Note:** Nested depth limits, forbidden character restrictions for directory names, and automatic cleanup of empty folders cannot be confirmed based on current documentation specifications.
