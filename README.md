# ✨ mcbCode [✨](https://loaf.mcbcode.com/new)

<img src="https://mcbcode.com/img/readme_banner.png">

**mcbCode** is a development platform for creating Minecraft: Bedrock Edition content.

it started as a `.mcfunction` editor and grew into something much bigger: a place to create projects, manage files, build packs, and work on bedrock content without having to piece together ten different tools just to get something working.

built for beginners, useful for experienced creators, and made because apparently bedrock development needed another person trying to organize the chaos.

## what is mcbCode?

mcbCode is a workspace for Minecraft Bedrock creators.

instead of treating your project like a pile of files scattered across folders, mcbCode gives you a place to create, edit, organize, and manage the things that make up a bedrock project.

the goal isn't to replace every tool in the bedrock ecosystem. it's to make the process of actually **building things** easier.

whether you're writing your first command or managing a project with a ridiculous number of files, mcbCode is built to give you somewhere to do it.

## what can you do with it?

mcbCode is built around projects, files, and the tools you need to work with them.

### write and edit

* dedicated `.mcfunction` editing
* Minecraft Bedrock command syntax support
* JSON/JS editing and validation
* pixel art editing
* multiple editor modes
* customizable editor settings
* support for different bedrock project file types

### manage projects

* create and organize projects
* folders and multiple files within projects
* bedrock pack support
* project sharing
* collaboration tools
* project export
* account profiles
* profile customization

### everything around the editor

* notifications
* points system
* documentation and guides
* tools for working with bedrock development resources
* (mostly) mobile-friendly interfaces
* tools and features designed to make getting started easier

and because apparently one feature was never enough, mcbCode keeps growing.

## why does this exist?

Minecraft Bedrock development can get unnecessarily repetitive.

you write something, open Minecraft, test it, find out you made one tiny mistake, go back to your editor, fix it, test it again, and continue this beautiful cycle until the problem turns out to be a missing character.

generic editors can work, but they aren't really built around the way Bedrock creators actually work.

mcbCode was created to make that process less frustrating.

the idea is simple: **give bedrock creators a focused place to build their projects.**

not another giant development suite that expects you to already know everything. not just a text box for commands. a proper workspace for making bedrock content.

## getting started

the easiest way to use mcbCode is through the official website.

no installation or separate development environment is required. create an account, create a project, add your files, and start building.

mcbCode is designed to be approachable for people who are new to Bedrock development while still being useful once you know what you're doing.

## development

mcbCode is independently developed by a *solo* developer.

it started as a small project and has gradually grown into a much larger platform. new features, improvements, bug fixes, and random ideas continue to get added as development moves forward.

some parts of mcbCode also rely on services and infrastructure provided by platforms such as Cloudflare and GitHub.

## contributing

mcbCode is primarily developed independently, but feedback from the Bedrock community is always useful.

if you find a bug, have an idea, or think something could work better, the [feedback site](https://feedback.mcbcode.com) is a good place to start.

you can also open an issue or pull request on GitHub for problems or suggestions related to the project.
